Education page editor

Unlock the current page, edit the three tabs as plain HTML, then download a rebuilt education.html. Everything happens in this browser — nothing is uploaded anywhere.

1Unlock the current page

Loads education.html and decrypts it so you can edit what's inside.

2Edit the tabs

Plain HTML. The styles on the page (.entry, .tag, .cards, the certification table) all still apply.

3Rebuild & download

Leave the password blank to keep the current one, or type a new one to change it.

Last step: upload the downloaded education.html to your repo (GitHub → the file → Add file / Upload files, or drag it in), replacing the old one. It goes live in about a minute.
